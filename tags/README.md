# Локальная копия раздела «Теги»

Самостоятельный прототип раздела UIS, собранный по доступному браузерному интерфейсу.

## Запуск

Из папки `tags-local`:

```bash
python3 -m http.server 4173
```

Открыть: <http://127.0.0.1:4173/>

## Реализовано

- список тегов и исходные данные первой страницы;
- поиск, фильтр статуса, сортировка и пагинация;
- создание и редактирование тега;
- подтверждение удаления;
- история простановки тегов;
- локальные шрифты и иконки UIS;
- адаптация к узкому окну через горизонтальную прокрутку рабочего пространства.

Данные хранятся в памяти вкладки и восстанавливаются после обновления страницы.
