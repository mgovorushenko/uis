# Дашборд UIS

Страница подключает штатный Dashboard из `@comagic/reports`. Версии reports, UI и charts зафиксированы по сборке кабинета UIS. Форма, валидация, стили и отрисовка виджетов поставляются этими пакетами. В `fixtures.js` находятся тестовые справочники, ответы отчётов и хранение состояния в браузере.

Для сборки из этой папки:

```sh
npm ci
npm run build
```

Запустите HTTP-сервер из корня проекта сценариев. Страница доступна по `/dashboards/`, а `/dashboards/?create` сразу открывает окно создания виджета. Для статического хостинга в сборку сайта нужно включить сгенерированную папку `dashboards/app/`.
